# Lab 02: AI in Everyday Challenges — ChronosAI

## Overview
This directory contains the individual product design and functional Python prototype for **Lab 02 (LLM Everyday Life)** in **PUSL 3205 — Large Language Models and Generative AI**. Addressing **"The Busy Student"** challenge, **ChronosAI** acts as an LLM-powered academic co-pilot that converts unstructured student reminders into structured task metadata, schedules work by cognitive energy levels, detects weekly burnout risks, and generates daily morning briefings.
